# Dream Big Travel

A travel website for exploring destinations and discovering travel packages across India.

## About

Dream Big Travel helps travellers explore destinations and find travel packages for their next adventure. The website provides information about destinations, packages, and contact details.

## Features

- Home page with a travel-themed design
- Explore popular destinations
- Browse travel packages
- About Us section
- Contact information and social media links
- Responsive website design

## Technologies Used

- HTML5
- CSS3
- JavaScript
